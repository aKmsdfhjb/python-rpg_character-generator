# RPG Character Generator — Video Production Brief

**Target:** 35 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

A compact demo of the real browser form: enter a valid name, allocate STR/INT/CHA to total seven points, and show the generated stat sheet. Then show a validation error for an invalid allocation. Keep it friendly and clearly label the tool as a character-sheet utility.

## Shot list

0–5s: title card. 5–15s: fill in character name and stats. 15–23s: show the generated ten-slot stat bars. 23–29s: demonstrate validation feedback. 29–35s: Python function, browser UI and repo.

## Voiceover draft

A small character builder that validates a name and a seven-point attribute budget, then renders a readable RPG stat sheet.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify any prediction, API response or feature shown in the edit.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.

## Generation prompt

Create a 35 seconds 16:9 1080p editorial software-project showcase for “RPG Character Generator”. Follow a warm ivory, black serif and vermilion monospaced Swiss portfolio aesthetic with precise grid alignment, thin rules, subtle transitions and clean screen-recording inserts. Use authentic project screenshots and the shot list above. Keep typography crisp and restrained. Do not fabricate UI, model outputs, performance metrics, users, testimonials or product capabilities. Avoid generic AI robots and neon sci-fi visuals. Finish on a quiet title card with the project name and GitHub repository.
