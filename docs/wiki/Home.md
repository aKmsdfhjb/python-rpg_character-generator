# RPG Character Generator — Project Wiki

A Python validator and browser companion for creating a character sheet with Strength, Intelligence and Charisma attributes.

## Quick start

```bash
python main.py
```
Open `index.html` for the browser companion. A valid character name is non-empty, at most 10 characters and contains no spaces. Each stat is 1–4 and all three stats total exactly 7.
